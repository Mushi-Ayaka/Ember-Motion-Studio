# Empezar rápido

Estos archivos contienen la documentación para desarrolladores de Ember Motion Studio.

Pasos mínimos para arrancar en desarrollo:

1. Instalar Node (v16+ recomendado) y pnpm.
2. Desde la raíz del repo ejecutar:

```bash
pnpm install
pnpm dev
```

3. Para ver esta documentación en local, sirve la carpeta `developer_docs` con un servidor estático, por ejemplo:

```bash
npx http-server developer_docs -o
```

4. Archivos clave: `app/`, `electron/`, `src/`, `plugin-src/`, `scripts/`.
