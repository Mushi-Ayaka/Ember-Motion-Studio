# Checklist de onboarding rápido

Objetivo: volver productivo en un día.

1. Leer `developer_docs/md/getting-started.md` y `architecture.md`.
2. Ejecutar `pnpm install` y `pnpm dev`.
3. Abrir el proyecto en el editor y localizar `electron/main.ts` y `App.tsx`.
4. Revisa `plugin-src/` si vas a tocar integraciones.
5. Hacer un cambio pequeño, abrir PR y validar el flujo de release localmente.
